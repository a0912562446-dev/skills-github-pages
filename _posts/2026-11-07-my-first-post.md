## 我已经学会了什么

- 创建分支，在独立的分支中修改文件。
- 提交修改，并通过 PR 检查和合并。
- 继续向同一分支提交时，现有 PR 会自动更新。
- 使用 Markdown 编写标题、任务清单、链接和代码块。
- 使用 GitHub Pages 发布学习网站。

## 我纠正的一个误解

我曾以为修改出错后，需要关闭 PR 再重新创建。
现在我知道，可以在原分支修正并提交，现有 PR 会自动更新。
